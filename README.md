## 装法

1. 下载 `JiuYi-Chengrenshu-v2.0.0.zip`
2. **解压到短路径**，比如 `D:\久益承认书2.0\`（路径太长或带特殊字符会起不来）
3. 双击 `久益承认书2.0.exe`，浏览器会自动打开
4. 首次要设资料库位置：右上角「设置」→「资料库位置」→ 填资料库文件夹路径 → 「测试」→ 保存

解压后约 177 MB / 1185 个文件。不需要装 Python。

## 资料库

程序本身不含供应商证据资料库，要单独下 `JiuYi-ZiliaoKu-v1.0-20260830.zip`（68 MB）。

解压后是一个 `供应商资料库/` 文件夹，把它整个放到固定路径（比如 `D:\久益资料库\`，
以后别随便挪），然后在程序里「设置 → 资料库位置」指向它。

包里还有两份说明：`资料库说明.txt`（目录怎么组织、日常怎么维护）和
`体检报告.txt`（这一版交付时的完整体检结果）。
