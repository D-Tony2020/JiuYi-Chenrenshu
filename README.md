# 久益 · 承认书制作系统 v2.0.0

这个仓库只用来**传安装包**，不是源码仓。源码在本地 `久益-承认书2.0/`。

## ⚠️ 这个仓库必须保持 Private

`JiuYi-Chengrenshu-v2.0.0.zip` 里**内置了明文 API key**
（`_internal/keys/_deepseek_key.txt`、`_qwen_key.txt`、`_internal/vendor/hitl/data/_api_key.txt`）。
这是刻意的——客户开箱即用，仓管员不用配任何东西。

**git 历史是永久的**：一旦推上来，就算以后删掉文件，key 仍然留在历史里。所以：

- ❌ 不要把这个仓转成 Public
- ❌ 不要直接加久益的人当 Collaborator
- ✅ 要给久益，用本地 `发布/` 里那份 zip 直接传给他们（U 盘 / 内网 / 他们的企业网盘）

## 装法

1. 下载 `JiuYi-Chengrenshu-v2.0.0.zip`
2. **解压到短路径**，比如 `D:\久益承认书2.0\`（路径太长或带特殊字符会起不来）
3. 双击 `久益承认书2.0.exe`，浏览器会自动打开
4. 首次要设资料库位置：右上角「设置」→「资料库位置」→ 填资料库文件夹路径 → 「测试」→ 保存

解压后约 177 MB / 1185 个文件。不需要装 Python。

## 资料库要另外拿

程序本身不含供应商证据资料库。资料库包是
`久益资料库_v1.0_20260830.zip`（68 MB，PDF 148 份 · index.json 47 个），
在本地 `发布/` 目录里，没有推到这里。

## 客户想换成自己的 key

程序里「设置 → 识别密钥」填，存在客户自己机器的
`%APPDATA%\Moore\久益-承认书2.0\config.json`，优先级高于随包内置的那份。
